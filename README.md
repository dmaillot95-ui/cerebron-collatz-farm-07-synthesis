# CÉRÉBRON Ω — Collatz Farm 07 Synthesis

Mission: fusionner les sorties des fermes 01–06 en une synthèse unique, traçable et auditée.

Règles:
- REALITY > COHERENCE
- EVIDENCE > CONFIDENCE
- CLAIM <= EVIDENCE
- CONSENSUS != TRUTH
- SIMULATION != TEST
- toute promotion de claim doit conserver sa provenance
- classer chaque élément: PROVED / REFUTED / HOLD / UNKNOWN
- CYCLES OPEN sauf démonstration arbitraire-N complète et auditée

Cette ferme ne doit pas inventer de preuve manquante. Elle fusionne, compare, déduplique, détecte contradictions et produit le paquet final pour le Master Hub.
